# 大豆点云采集容器 · 扫描动画运动方案

> 全部数值由 pi 扩展 motion-planner 确定性计算（motion_compute / motion_collide），LLM 仅编排。
> 场景文件：`大豆点云采集容器.blend` ｜ 30 fps ｜ 帧范围 1–285

## 1. 运动目标

共享激光雷达沿顶部滑轨依次服务 P1/P2/P3 三株大豆，流程为"移动 → 定位 → 停稳 → 扫描 → 保存 → 前往下一株"，结束后复位至 P1。

## 2. 运动计划（motion_compute 输出）

| 段类型 | 帧 | 位置（X, m） | 说明 |
|---|---|---|---|
| 停留 P1 | 1–30 | −0.5 | 扫描 P1（幼苗期） |
| 移动 | 30–66 | −0.5 → 0 | smoothstep 缓动 |
| 停留 P2 | 66–125 | 0 | 扫描 P2（开花期） |
| 移动 | 125–161 | 0 → 0.5 | |
| 停留 P3 | 161–220 | 0.5 | 扫描 P3（结荚期） |
| 移动（复位） | 220–256 | 0.5 → −0.5 | 返回首站 |
| 停留 P1 | 256–285 | −0.5 | 复位完成 |

- 关键帧（7 个）：(1,−0.5) (30,−0.5) (66,0) (125,0) (161,0.5) (220,0.5) (256,−0.5)
- 峰值速度：1.25 m/s（0.5 m 行程 × 1.5 峰值系数 ÷ 1.2 s）
- 雷达自旋：全程匀速 4 圈（0→1440°，线性插值），两帧关键帧

## 3. 碰撞检测（motion_collide 输出：PASS）

- 代理：运动件 = 滑块 AABB + 雷达 AABB（导出帧世界坐标，随轨迹平移）；静态件 = 24 个（3 舱顶框/立柱、龙门横梁/立柱、双电机、控制箱）
- 逐帧扫掠 1–256 帧、安全间隙 0.01 m：**零碰撞**
- 全程最小间隙 0.02 m（滑块底 ↔ 横梁顶，恒定——滑块始终骑在轨道上方）
- 雷达底面 0.665 m，高于舱顶 0.60 m，静态间隙 0.065 m

## 4. 点云表现（到达后出现，非移动点云）

- 点云形状贴合植株：叶层盘簇 62% + 茎线点 22% + 根部土表环 16%
- 每株 110 点（1320 顶点），绿色发光（MAT_点云）
- 可见性严格对齐扫描窗口：P1 1–30 与 256–285、P2 66–125、P3 161–220
- 出现方式为原地显隐（无缩放/位移动画），保证"到达后才出现在对应植株上"
