# Pod Agent 写作规范

1. 先完整读取 [写作规范](../../../docs/development/writing.md)。
2. 涉及代码、接口或测试时，再读取对应开发规范与当前实现。
3. 明确目标读者、行动目标、范围和权威源；默认 Markdown 是唯一可编辑源。
4. 先组织结论与结构，再写正文；事实、链接、命令和代码必须可追溯或可复现。
5. 交付前检查术语、标题、链接、示例、差异和与当前代码的一致性。

普通项目文档不默认生成 PDF，也不创建空目录或多份同步源文件。
