# Python 原型开发规范

Python/FastAPI 只用于尚未验证、需要快速试错的算法或服务原型，不默认替换已经工作的 Rust/Tauri 主链路。

## 进入条件

仅在同时满足以下条件时引入 Python 原型：

1. 问题与用户价值尚未验证，预计会频繁改变算法或接口。
2. Python 生态能显著缩短验证周期，例如育种统计、模型实验或数据分析。
3. 已定义与 Tauri/Rust 解耦的输入、输出、错误和超时契约。
4. 已明确原型的退出条件：淘汰、保留为受控 sidecar，或迁移到 Rust。

## 工程要求

- 遵循 PEP 8 和项目已有依赖方式；不主动创建全局环境或安装全局包。
- FastAPI 层只做传输与校验，算法写成可独立测试的模块。
- 对密钥、文件路径、超时、取消、并发上限和进程退出做明确处理。
- Python sidecar 不得直接成为 SQLite 的第二个写入者；数据写入仍经 Rust 统一边界完成。
- 原型验证后记录基准、正确性、维护成本和迁移结论，再决定是否用 Rust 重写。
